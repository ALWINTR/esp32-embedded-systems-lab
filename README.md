A core embedded engineering and hardware prototyping repository containing low-level ESP32 peripheral drivers (UART, SPI, I2C, ADC, PWM), FreeRTOS dual-core task templates, and sensor communication routines.

---

## Architectural Modules

- **Peripheral Drivers**: Low-level register abstraction for high-speed hardware SPI, I2C master transceiver, multi-channel UART, and hardware timers.
- **FreeRTOS Kernel Templates**: Dual-core task distribution, thread-safe queue pipelines, binary semaphores, and timer interrupts.
- **Power Management**: Deep-sleep wake stubs, ULP coprocessor routines, and brownout protection configurations.
